# 🚗 Smart Parking Management System

A console-based **Smart Parking Management System** built using **C++** in **Visual Studio** to organize parking spaces, manage vehicle entries and exits, validate user inputs, and automatically calculate total revenue.

---

## 📋 Overview
Managing parking spaces and tracking daily revenue manually is prone to errors and delays. This system provides a clean, menu-driven interface that automates slot allocation, prevents invalid entries, and keeps real-time track of available spaces and earnings.

---

## ✨ Key Features
- **Welcome Message & Main Menu:** Clear interactive console navigation for quick operation.
- **Park a Car:** Assigns an available parking slot to an incoming vehicle and updates capacity.
- **Remove a Car:** Frees up a parking space upon vehicle exit and updates revenue calculations.
- **View Parking Spaces:** Displays real-time status of occupied and available parking slots.
- **Total Revenue Tracking:** Automatically calculates and displays accumulated parking earnings.
- **Input Validation:** Handles invalid inputs gracefully to prevent crashes or incorrect data.
